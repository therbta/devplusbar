Dev+ Bar 0.5: alerts for what needs you, and a lighter launch.

- **Workflow and comment alerts.** A workflow failing on the default branch of a repository
  you own, or a person commenting in a thread you're shown, now arrives as a banner and as a
  pop-up under the menu-bar icon.
- **Claude limit warnings.** A heads-up at 75% and 90% of your weekly Claude Code limit, and
  when your current pace would run out before the reset.
- **The weekly meter matches claude.ai.** It starts from the percentage Claude Code last
  fetched from Anthropic, cached on this Mac, so it no longer drifts away from claude.ai.
- **Workflows that never passed.** Deploys lists them, with a Disable button that asks first.
- **Unpushed work.** Local shows how long work has sat unpushed, folds parked repositories
  away, and nudges once after 24 hours.
- **Notifications off?** Settings now warns when macOS notifications are turned off for
  Dev+ Bar.
- **Faster, lighter start.** AI usage reads its logs in chunks, so memory at launch drops from
  about 2.3 GB to about 150 MB.

### Install

```sh
curl -fsSL https://devplusbar.pages.dev/install.sh | sh
```

or `brew install --cask therbta/tap/devplusbar` (`brew upgrade --cask devplusbar` to update).
