Dev+ Bar 0.4: deployments, local work and AI usage next to your pull requests.

- **Deploys (Vercel, Heroku).** Connect a token in Settings › Deployments to get a card per
  deployment with a live build timer, the failure line from the build log, and links to the
  site, logs and pull request. A production strip per project, Insights charts (deploys per
  day, build time, success rate, recovery time), and optional redeploy and roll back that
  ask first.
- **CI on production branches.** A project whose latest GitHub Actions run failed gets a red
  CI ✗ with the failed step's last lines and a copyable prompt for a coding agent.
- **Local.** Git repositories on this Mac with commits that aren't on GitHub yet, and the dev
  servers listening on a port, each with a Stop button. Runs only `git status`, `lsof` and
  `ps`; nothing leaves the Mac.
- **AI usage.** How much of your Claude limit window you've used, learned from local logs.
- **New notifications:** a check failing, a conflict or a merge on your own pull requests;
  someone answering in a thread you're in; a workflow on a default branch turning red.
- **⌥⌘D** opens the panel from anywhere.
- Now signed with a Developer ID certificate and notarized by Apple.

### Install

```sh
curl -fsSL https://devplusbar.pages.dev/install.sh | sh
```

or `brew install --cask therbta/tap/devplusbar` (`brew upgrade --cask devplusbar` to update).
